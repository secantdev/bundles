# Project brief

A brief has four short sections:

1. **Problem**: who has it and what it costs them today.
2. **Outcome**: what is true when the project is done, in one or two sentences.
3. **Out of scope**: what the project will not do.
4. **Open questions**: what nobody knows yet.

Ask about the section with the biggest gap first. Offer your own best guess with each question so the user can just say yes. Keep the brief under 300 words, and read it back before you write it.
